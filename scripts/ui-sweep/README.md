# UI sweep (UI-SWEEP-1)

`sweep.mjs` presses every clickable control and listed shortcut on every screen of a packaged Blurby build over the Chrome DevTools Protocol, and writes a report that classifies each press as OK, ERROR, NO-EFFECT, SKIPPED-SAFETY, SKIPPED-DIALOG or UNREACHABLE. It uses Node 24 built-ins only, and it runs only on a scratch profile. Run it from a *copy* of `release\win-<arch>-unpacked`, because deleting the sample book deletes the bundled file from the build (BUG-194). Pass `--live-profile %APPDATA%\blurby\blurby-data` so the report proves the real profile is unchanged. Real run: `node scripts/ui-sweep/sweep.mjs --exe <copy>\Blurby.exe --profile <empty scratch dir> --seed <epub>,<pdf>,<txt> --artifacts C:\Projects\Blurby-artifacts\ui-sweep-1 --report docs/studies/investigations/UI-SWEEP-1.2026-10-23.md --live-profile %APPDATA%\blurby\blurby-data [--models <Narrate models root>] [--only "<surface name>,..."]`. Engine self-test, which opens no Blurby window: `node scripts/ui-sweep/sweep.mjs --dry-run --browser "<msedge.exe>" --artifacts <dir> --report <dir>\dryrun-report.md` runs headless Edge on a page of known controls, and exits 0 only when every expected classification holds. The script exits 3 when the BUG-187 positive control finds nothing.
