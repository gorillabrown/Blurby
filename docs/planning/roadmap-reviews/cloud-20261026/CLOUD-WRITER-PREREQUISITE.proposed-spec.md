### 1. Successful payload provenance

Revalidate current local content/replacement/account authority; use CURRENT local docs and applicable ORIGINAL raw remote operand with existing mergeLibrary and GC ordering. type RawRemoteRead = { attempt: number; bytes: Uint8Array; sha256: string;
  data: unknown; etag: string|null; generation: string|null; revision: number|null };

type ConditionalWriteOutcome =
  | { ok: true; actualWritten: ActualWritten; attempts: readonly WriteAttempt[] }
